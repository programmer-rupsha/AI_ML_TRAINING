## 🧠 Featured Projects

### 📊 Project 1 — EDA Dashboard (Titanic Dataset)
> *Exploratory Data Analysis · Visual Insights*

- Loaded the Titanic dataset and explored columns using **Pandas**
- Handled missing values via **mean & mode** imputation
- Built visualizations: survival count, gender vs survival, age distribution
- Summarized actionable insights — presentation-ready

**Tech Stack:** `Python` · `Pandas` · `Matplotlib`

---

### 🏠 Project 2 — House Price Prediction
> *Supervised Machine Learning · Linear Regression · Model Evaluation*

- Performed **train-test split** to evaluate on unseen data
- Trained a **Linear Regression** model using `scikit-learn`
- Evaluated performance using **RMSE** and **R² score**
- Visualized **Actual vs Predicted** values and residual errors

**Tech Stack:** `Python` · `scikit-learn` · `Pandas` · `Matplotlib`
